# Multi Agent-AI-Software-Engineering-Platform

A multi-agent AI platform that automates key stages of the Software Development Life Cycle from a natural-language project description.

## Features

- Requirements analysis
- Project planning
- System architecture generation
- Automated QA/test planning
- DevOps planning
- Task allocation and scheduling
- Real-time agent monitoring
- Local LLM inference using Ollama and Llama 3
- Fallback engine when the local model is unavailable

## Tech Stack

- React.js, Vite
- Node.js, Express.js
- Ollama, Llama 3
- JWT Authentication
- REST APIs
- JSON persistence

## Workflow

**Project Idea → AI Agents → Requirements → Planning → Architecture → QA → DevOps → Task Schedule**
